# Рогатка: Поймай цыпу

React + Vite + Tailwind CSS.

## Запуск

1. Установи Node.js (https://nodejs.org), если его ещё нет.
2. Открой папку в VS Code (File → Open Folder).
3. Открой терминал (Ctrl+`) и выполни:

```
npm install
npm run dev
```

4. Открой адрес из терминала (обычно http://localhost:5173).


**Промпт: **
Создай игру «Рогатка: Поймай цыпу!» одним файлом на React (функциональный компонент App, export default). Стили через Tailwind CSS, иконки из lucide-react (Play, RotateCcw, Volume2, VolumeX, Trophy, Heart, Zap, Sparkles, Award). Игра рисуется на <canvas> через requestAnimationFrame. Весь интерфейс на русском языке. Работает и на мышке, и на телефоне (touch), полноэкранная.

УПРАВЛЕНИЕ
- Рогатка стоит по центру, на 66% высоты экрана.
- Игрок нажимает в любом месте экрана и оттягивает рогатку, отпускает — камень летит в противоположную сторону от оттяжки.
- Сила выстрела зависит от длины оттяжки (максимум ограничен радиусом, который масштабируется от размера экрана).
- Пока игрок тянет, показывается пунктирная траектория, которая учитывает гравитацию и ветер.
- Если мышь отпущена за пределами canvas, выстрел всё равно происходит (onMouseLeave).

ПТИЦЫ (летят слева направо и наоборот в верхней части экрана; чем больше очков — тем быстрее птица: скорость = 0.6 + очки × 0.3)
- 🐥 Цыпа, 1 очко, самая медленная, появляется чаще всех. Единственная птица, которая отнимает 1 жизнь, если улетела за экран.
- 🐔 Курица, 2 очка + 3 камня в запас.
- 🐓 Петух, 3 очка, летит волной, даёт щит (спасает от следующей потери жизни, работает один раз).
- 🦆 Утка, 5 очков, +1 жизнь и случайный особый камень.
- 🦅 Золотой орёл, 10 очков, очень быстрый и редкий, +1 жизнь (с 2 уровня).
- 🐧 Пингвин, 2 очка, замедляет время на 6 секунд.
- 🦇 Бомбардир (с 3 уровня), 3 очка, роняет яйца 🥚. Яйцо, долетевшее до земли, отнимает жизнь, но его можно сбить камнем (+1 очко).
- Все птицы, кроме цыпы, при вылете за экран жизнь НЕ отнимают.

ОСНОВНЫЕ ПРАВИЛА
- 5 жизней (в интерфейсе 5 сердечек, при старте тоже 5). Максимум 5.
- Игра заканчивается при 0 жизней. Рекорд сохраняется в localStorage (внутри try/catch).
- Уровень = очки / 10 + 1. Чем выше уровень, тем быстрее птицы и чаще они появляются.
- Комбо: каждое попадание подряд увеличивает комбо, каждые 3 попадания дают множитель очков (×2, ×3 ... максимум ×5). Промах камнем или потеря жизни сбрасывают комбо.
- Камни ограничены: старт 8, максимум 10. Попадание возвращает камень (бонусные птицы — 2), плюс +1 камень каждые 5 секунд.

ОСОБЫЕ КАМНИ (выпадают при попадании в утку, действуют на следующий выстрел)
- 💥 Взрывной: сбивает всех птиц в радиусе 110 px.
- 🔱 Тройной: летит веером из трёх камней.
- ⛏️ Тяжёлый: крупнее и пробивает птиц насквозь.

ДОПОЛНИТЕЛЬНО
- Ветер с 2 уровня: меняется каждые 6–11 секунд, на экране стрелка с надписью «ВЕТЕР», сносит камень.
- Босс-индюк 🦃 каждые 5 уровней: 6 попаданий, полоска здоровья, двигается из стороны в сторону, 30 секунд на победу. Победа: +30 очков и +1 жизнь. Если убежал: −2 жизни.
- Фон меняется по уровням: утро, день, закат, ночь (со звёздами, луной и светлячками).
- Частицы при попадании и всплывающие тексты («+3», «×2», «🛡️ Щит!»).
- Звуки синтезируются через Web Audio API (без файлов): натяжение, выстрел, попадание, взрыв, бонус, заморозка, промах, конец игры. Кнопка вкл/выкл звука.

ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ
- Движение считать через delta time (dt × 60), чтобы скорость не зависела от частоты монитора.
- Изменяемые данные игры (счёт, жизни, комбо, камни, объекты на экране) хранить в useRef, а в React-состояние копировать только для HUD, чтобы не было устаревших значений в цикле анимации. Побочные эффекты (localStorage, смена экрана) не вызывать внутри setState.
- Стартовый экран: название, легенда всех птиц с их бонусами, короткие правила, рекорд, кнопка «Играть!».
- Экран «Игра окончена!»: счёт, рекорд, кнопка «Играть снова».
- HUD сверху: очки, уровень, комбо с множителем, жизни, кнопка звука. Снизу: индикатор камней, особый камень, щит, замедление.
- Стиль: яркий мультяшный, скруглённые полупрозрачные панели, эмодзи вместо картинок.
